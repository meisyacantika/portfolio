# Meisya Cantika — Personal Portfolio

Personal portfolio website showcasing academic projects, data analytics work, and verified certifications.

Built with **React**, **TypeScript**, **Tailwind CSS v4**, and **Vite**.

## 🚀 Getting Started

### Prerequisites
- Node.js (v20+)
- npm

### Installation & Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
```
The compiled output will be generated in the `dist/` directory.

## 🛠 Tech Stack
- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Wouter, Lucide React
- **Bundler & Tooling**: Vite 7
