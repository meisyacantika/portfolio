## ✨ Key Features & Sections

- **01 // Overview & Headline**: Highlighting academic focus, technical skills, and career trajectory in Data Analytics, Data Science, and Engineering.
- **02 // Journey & Background**: Chronological educational background, leadership, and hands-on milestones.
- **03 // Project Showcase**: Deep dives into end-to-end technical projects (system architecture, database design, data processing, and business insights).
- **04 // Verified Credentials**: Interactive certificates list with direct links to credential verification providers.
- **Responsive & Modern UI**: Built with a sleek dark-themed aesthetic, fluid animations, and mobile-friendly navigation.

## 🚀 Local Development

If you want to run this project locally on your machine:

### Prerequisites
- [Node.js](https://nodejs.org/) (v20 or higher recommended)
- `npm`

### Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/meisyacantika/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the local development server**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
```
The optimized production output will be generated in the `dist/` directory.
